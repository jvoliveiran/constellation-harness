# Ideas Parking Lot

Good ideas wait here — parking is a success (scope defended), not a rejection. The Product Manager reviews this file at the start of every Discovery session and roadmap update; ideas whose triggers fired get promoted before new ideas are invented.

Rules:
- Every parked idea has a **revisit trigger** — a data signal or event, never "someday"
- Never delete entries — mark them `promoted` or `dropped (reason)`

| Idea | Value hypothesis | Parked because | Revisit when | Status |
|---|---|---|---|---|
| _example: CSV export_ | _power users analyze offline_ | _not in the core loop for v1_ | _≥3 user requests OR retention loop stable_ | parked |
